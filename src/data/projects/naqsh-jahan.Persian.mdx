# معرفی

**نقش جهان** یک پروژه توسعه وب است که با هدف ایجاد یک تجربه دیجیتال با الهام از هویت فرهنگی و معماری نقش جهان طراحی شده است.

این پروژه بر ارائه محتوا از طریق یک رابط کاربری مدرن و استفاده از روش‌های امروزی توسعه فرانت‌اند تمرکز دارد.

## جزئیات فنی

- **فرانت‌اند:** Next.js و React
- **زبان برنامه‌نویسی:** TypeScript
- **استایل‌دهی:** CSS
- **استقرار:** Vercel

## اهداف توسعه

- طراحی رابط کاربری مدرن و قابل استفاده.
- سازمان‌دهی کد در قالب کامپوننت‌های قابل استفاده مجدد.
- پیاده‌سازی طراحی واکنش‌گرا برای نمایشگرهای مختلف.
- ایجاد ساختاری خوانا و قابل نگهداری.
- انتشار پروژه در محیط عمومی وب.

## نتیجه

پروژه نقش جهان تجربه عملی من در توسعه وب را نشان می‌دهد و طراحی رابط کاربری، پیاده‌سازی فرانت‌اند و استقرار یک پروژه تحت وب را در بر می‌گیرد.
